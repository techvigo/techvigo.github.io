# Makerere Academic Portfolio Website

A responsive static website presenting the certificate, passport photo, Makerere University branding supplied by the user, and an academic overview of Information Technology.

## Important verification design

This is a private academic portfolio, not an official Makerere University verification portal. The site deliberately does **not** claim that an uploaded certificate image has been independently authenticated. The certificate is displayed as a document supplied by the holder, with links to Makerere's official website and published programme information for independent confirmation.

## Run locally

1. Open this folder in VS Code.
2. Install the **Live Server** extension (optional but recommended).
3. Right-click `index.html` and choose **Open with Live Server**.
4. The site will open in your browser.

## Files

- `index.html` — website structure and content
- `styles.css` — responsive green/black/blue/white visual system
- `script.js` — mobile navigation and current footer year
- `assets/certificate.jpg` — supplied certificate image
- `assets/passport.jpg` — supplied passport photograph
- `assets/makerere-logo.jpg` — supplied Makerere logo image
